# Realtime Web Chat (WhatsApp Web Clone)

تطبيق دردشة ويب مباشر مخصص لشخصين فقط (`baraa` و `hams`)، مطور باستخدام تقنيات الويب الأساسية (Vanilla JS) ومتوافق مع GitHub Pages و Firebase Hosting.

## مميزات المشروع
- واجهة مستخدم داكنة مطابقة لـ WhatsApp Web.
- استخدام Firebase Realtime Database SDK v12.17.0 عبر ES Modules.
- مزامنة فورية للرسائل وحالات الاتصال ومؤشرات الكتابة.
- دعم تعديل وحذف الرسائل، والإرسال بزر Enter.
- دعم كامل للعمل مباشرة على GitHub Pages و Firebase Hosting بدون إعدادات إضافية.

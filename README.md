# Realtime Web Chat (WhatsApp Web Clone)

تطبيق دردشة ويب متكامل ومخصص لشخصين فقط (`baraa` و `hams`)، مصمم بمحاكاة كاملة لتجربة WhatsApp Web ومبني باستخدام Vanilla JavaScript و Firebase Realtime Database SDK v12.17.0.

## الميزات المضافة حديثاً
- 🎤 تسجيل وإرسال رسائل صوتية مباشرة.
- 📎 إرسال ومعاينة الصور والملفات.
- ❤️ التفاعل بالإيموجي على الرسائل (Reactions).
- 📌 تثبيت الرسائل الهامة في الأعلى.
- 🌙 دعم الوضع الفاتح والداكن (Light/Dark Mode).
- ⌚ عرض حالة "آخر ظهور" بدقة.
- 📅 فواصل زمنيّة وأيام تلقائية بين الرسائل.
- 🗑️ حذف الرسائل ليظهر "تم حذف الرسالة".
- 🔍 محرك بحث داخل المحادثة بشكل لحظي.
- 🔔 إشعارات المتصفح (Push Notifications) عند وصول رسالة والصفحة مغلقة.
- ⚡ تحسين الأداء والأمان ومنع ثغرات XSS.
- 📱 تصميم متجاوب بالكامل للأجهزة الذكية وأجهزة الكمبيوتر.
